NVIDIA Contract

After VLM generate (T=0.6, top_p=0.98, StopAfterEOS on <|traj_future_start|> plus one token), src/alpamayo_r1/models/alpamayo_r1.py does:

  1. action_in_proj(x, t) — PerWaypointActionInProjV2, Fourier + MLP, LayerNorm → (B, 64, 2048).
  2. Expert forward on those 64 tokens with VLM past_key_values, 3-row position_ids = arange(64) + rope_deltas + (traj_future_start + 1), and a mask that hides pad / the extra EOS token between that offset and the diffusion tokens.
  3. expert_non_causal_attention=true — diffusion tokens attend to each other fully.
  4. Crop cache back to prefill length after each Euler step.
  5. action_out_proj is Linear(2048, 2) → accel / curvature.
  6. FlowMatching.sample (Euler, 10 steps) then action_to_traj. Reshape (B, num_traj_sets, num_traj_samples, 64, 3).

Checkpoint: n_waypoints=64, expert hidden 2048 / 16 heads / head_dim 128 / intermediate 8256, action_in_proj_cfg hidden 512, 2 enc layers, 20 Fourier feats.

VLM KV prefix (4096 → 2048)

This is not a naive cache share of hidden states. VLM hidden is 4096; expert hidden is 2048. Shapes still match because expert_cfg does not override num_key_value_heads or layer count. Both sides store K/V as [B, 8, S, 128] (GQA). Expert queries (16 heads) attend to VLM-produced keys/values, then append their own 64-token K/V, then crop.

The expert is now an mlx_vlm Qwen3-VL attention wrapper (not stock mlx_lm Qwen3). After VLM generate, sync cache._idx = offset — _idx is set at the start of a VLM call and is one token behind. The pad mask must be the expert dtype (bfloat16).

Landed this split
  • PerWaypointActionInProjV2 — mlx_port/models/action_in_proj_mlx.py. Checkpoint key names match. Numerical test vs NVIDIA PyTorch module.
  • ActionOutProj — bare nn.Linear so keys are action_out_proj.weight / .bias (not .linear.weight).
  • n_waypoints=64 — ActionSpace.get_action_space_dims() uses self.n_waypoints. from_pretrained no longer pops 64, so diffusion x_dims is (64, 2).
  • AlpamayoExpert — mlx_vlm Qwen3-VL attention wrapper. Keeps VLM GQA (8 KV heads) and 36 layers; width is 2048 / 16 Q heads. Weight remap unchanged.
  • step_fn — sample_trajectories_from_data_with_vlm_rollout now runs action_in_proj → expert + VLM KV prefix → action_out_proj → Euler sample → action_to_traj. Uses VLM _rope_deltas, prompt+generated offset, pad mask, cache trim. Temperature e2e loads the expert.
