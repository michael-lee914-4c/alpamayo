Stage 1c: Runtime / Inference Speedup
4–8 days • Blocks SFT • P0 landed
IN PROGRESS
Why this is now in the port
A full window (encode → prefill → CoC decode → 10-step flow-matching) is ~110 s on M4 Max. That is a port/pipeline problem, not a 128 GiB memory problem. NVIDIA’s own SFT graph is encode + one backbone forward + one expert CFM step — not a 110 s rollout. Execute the phases in alpamayo1-mlx-speedup-plan.html in order. A phase is done only when its gate table is green.
Bar A — Diagnose
Stage timer on a fixed clip: encode / prefill / CoT decode / FM. Dtype, compile, num_traj_samples, FM steps, max CoT tokens.
Bar B — Trainable
Teacher-forced or CoT-off train step in tens of seconds or less. LoRA/QLoRA path works. Do not call the infer rollout every step.
Bar C — Fast infer
Toward a few seconds, then <2 s if stream + speculative CoT land. ADE within ~0.1–0.2 m of bf16 on a frozen 50-clip slice.
Phases (G1 signed off 2026-08-29)
  1. P0 Inventory — map modules to the four stages; count mx.eval / host roundtrips.
  2. P1 Profile — G1 signed off 2026-08-29 on the P2f greedy table (one cold trial; user accepted).
  3. P2 Compile / dtype / cut work — bf16 hot path, mx.compile FM + a backbone block, kill per-step eval, train knobs (1 traj, FM 4–6, CoT cap 32–64 or 0).
  4. P3 Mixed PTQ — 4-bit language tower only after G2. Expert and vision stay denser. ParoQuant preferred over naive affine for CoT.
  5. T4.3 Train graph — replace rollout-in-the-loop with official Stage-1 CE / Stage-2 CFM. Bigger win than 4-bit if the current “train” path generates.

Phases 5–6 (stream KV, speculative CoT, adaptive FM, distill a student) are in the speedup plan. They are how infer leaves the multi-second regime; they are not required to start a Stage 2 smoke once Bar B is green.

Do not
  • • Quantize the whole model to uniform 4-bit as the first change, or 4-bit the expert/vision before the language tower is proven.
  • • Start a multi-day QLoRA run before Phase 1 timers exist. Do not backprop through packed QuantizedLinear.weight.
  • • Set num_traj_samples>1 or max_generation_length=256 inside a training loop.
  • • Claim “FlashDrive on Mac.” Steal algorithms; reimplement with compiled MLX closures.
